Separate your visual design from your backend logic. Design beautiful templates with a drag-and-drop WPF editor, and render them dynamically in any .NET application using JSON data.

Why FastReport?

Built for performance, flexibility, and ease of use.

Visual Designer

A standalone WPF desktop application with drag-and-drop capabilities. Save templates as lightweight .frpt (JSON) files.

Dynamic JSON Binding

Inject dynamic data into your reports instantly using double-brace template syntax like {{Customer.Name}}.

Cross-Platform Engine

A pure .NET 8 library powered by QuestPDF. Run it in ASP.NET Core APIs, Worker Services, or Console apps on any OS.

Native RTL Support

Flawless rendering for right-to-left languages (Persian/Arabic) with proper text shaping and connected characters out of the box.

Integrated Charts

Native support for rendering Bar and Pie charts dynamically using ScottPlot based on JSON data arrays.

No HTML Conversion

Forget browser dependencies like Puppeteer or WkHtmlToPdf. Generates optimized, vector-based PDFs natively.

How It Works

Generate professional reports in three simple steps.

1

Design your template

Open the FastReport WPF Designer, drag your text boxes and charts, bind them to JSON paths (e.g. {{Customer.FullName}}), and save as Invoice.frpt.

2

Install the NuGet Package

dotnet add package FastReportEngine
3

Generate PDF in C#

using FastReport.Domain;

// 1. Prepare your dynamic data as a JSON string
string customerDataJson = @"{
    ""Customer"": { 
        ""FullName"": ""علی رضایی"" 
    },
    ""TotalAmount"": ""5,400,000 تومان""
}";

// 2. Initialize the engine and generate the PDF
var engine = new ReportEngine();

engine.RenderPdf(
    templateFilePath: "Invoice.frpt", 
    jsonData: customerDataJson,
    outputPdfPath: "FinalInvoice.pdf"
);
